# Glosario

| Concepto | Significado |
| --- | --- |
| Kioku | Nombre oficial; 記憶. «Memoria» fue un nombre provisional. |
| Turn / intervención | Entrada enviada por texto o terminada al soltar/finalizar la voz. No equivale a toda la conversación. |
| Source / relato | Texto original conservado con su contexto y procedencia. |
| Memory / recuerdo | Unidad recuperable derivada de uno o varios fragmentos del relato. |
| Intent / intención de entrada | Contar o preguntar; distinta de un deseo descrito dentro del contenido. |
| Claim kind | Hecho relatado, intención/deseo, opinión, pensamiento o dato temporal. |
| Clarification | Pregunta necesaria para resolver una ambigüedad antes de guardar, responder o actuar. |
| Proposal | Oferta pendiente de guardar un dato nuevo en una consulta; no es todavía un recuerdo. |
| Correction | Instrucción de sustituir un dato erróneo; no es necesariamente un cambio real de opinión con el tiempo. |
| Forget | Retirar el contenido indicado de la memoria y de sus representaciones derivadas. |
| Source evidence | Texto autorizado que sustenta una respuesta, sin garantía de que el hecho haya ocurrido fuera de lo contado. |
| Credential reference | Identificador privado de una credencial del servidor; nunca su valor secreto. |

Los nombres de tipos, rutas, identificadores y código son ingleses; los textos iniciales de producto son españoles. Todos los ejemplos publicados son ficticios.
