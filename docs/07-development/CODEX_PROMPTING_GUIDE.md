# Preparar tareas para Codex

Aplicar esta guía cuando el propietario pida preparar un prompt para otra sesión, no como confirmación repetitiva antes de cada acción ya autorizada.

Un prompt útil contiene: objetivo acotado, FR/UC/ADR pertinentes, criterios de aceptación, límites, estado real del repositorio, comprobaciones necesarias y entregable. Pedir a Codex que lea solo las fuentes relevantes y responda al propietario en español. El prompt técnico puede redactarse en inglés si lo solicita o facilita el traspaso.

Si se recomienda modelo/esfuerzo, usar un modelo realmente disponible y un nivel admitido, justificar coste/riesgo y no inventar nombres ni congelar un catálogo que caduca. La recomendación no cambia por sí sola el modelo de ejecución.

No incluir secretos ni rutas personales. No mandar crear una arquitectura paralela, restaurar Expo, usar IDs de Wonderdrop, modificar Stitch sin petición, ejecutar suites ajenas ni declarar que Firebase/IA ya funcionan.

Las instrucciones de la sesión y la autorización vigente prevalecen. Esta guía no introduce un bloqueo de permisos o de selección de modelo distinto del pedido por el propietario.
